# ⏱️ Stopwatch

## 📌 About the Project

This is a simple and responsive Stopwatch application built using HTML, CSS, and JavaScript. It allows users to measure elapsed time with an easy-to-use interface.

## ✨ Features

* ▶️ Start the stopwatch
* ⏸️ Pause the stopwatch
* 🔄 Reset the stopwatch to zero
* ⏱️ Display elapsed time in real time
* 🎨 Simple and user-friendly interface
* 📱 Responsive design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder in VS Code.
3. Open `index.html` in your browser or use the Live Server extension.
